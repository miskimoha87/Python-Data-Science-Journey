Welcome to **Day 3** of my Python Data Science learning journey. In this lesson, I learned essential data cleaning techniques using the Pandas library. These operations help prepare datasets for accurate analysis and improve overall data quality.

# 📖 Lesson Overview

The main objective of this lesson was to understand how to modify dataset structures, replace incorrect values, remove unnecessary columns, and convert data into appropriate data types for analysis.

---

# ✅ Topics Covered

- Renamed columns using `rename()`.
- Replaced inconsistent values using `replace()`.
- Removed unnecessary columns using `drop()`.
- Checked dataset data types using `dtypes`.
- Converted columns to numeric data types using `pd.to_numeric()`.
- Prepared the dataset for data cleaning and analysis.

---

# 🔄 Process

1. Imported the dataset into Pandas.

5. Removed unnecessary columns from the dataset.
6. Checked column data types.
7. Converted selected columns to numeric data types.
8. Verified the updated dataset structure.
